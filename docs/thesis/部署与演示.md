# 部署、演示、许可和局限

## 启动

本机 5432 和 8000 已被其他项目占用。FinScope 使用：

```powershell
$env:FINSCOPE_DB_PORT = "54329"
$env:FINSCOPE_API_PORT = "18000"
$env:FINSCOPE_WEB_PORT = "8080"
docker compose up --build -d
```

页面：http://localhost:8080  
接口：http://localhost:18000

登录账号在开发库里是 `admin` / `Admin-pass-1`。不要把这个口令用于生产。

## 演示顺序

1. 首页看服务是否就绪。
2. 美国宏观看 vintage，没有密钥时序列不可用。
3. 日线看贵州茅台、中国平安、五粮液。没有 K 线时不补价格。
4. SEC 样例和公司研究对比 2022-12-31 与 2023-12-31。80 和 120 是夹具，不是苹果真实收入。
5. 保存研究记录，点开 80，核对申报号。
6. 上传一份文字版 PDF，用原文检索页码。
7. 行业假设：120 作为支持，50 shares 作为反证，状态是 contested。
8. 市场温度在成分不足时显示无法判断。
9. 研究板里的中国宏观和社融保持不可用，直到导入带来源的 CSV。
10. 研究推演用 600519.SH。2026-06-01 看不到中报，2026-08-16 看得到。评级不是下单。

## 数据许可

- 美国宏观来自 FRED，需要密钥，并遵守 FRED 使用条款。
- 美股事实样例来自 SEC companyfacts 的本地夹具。
- A 股日线经东方财富公开行情接口，页面不称实时。
- 茅台两期累计收入和披露日写在规格书 21.4，只用于 Mock 回放。
- 巨潮、交易所公告只保存标题、时间和链接，不转载全文。
- TradingAgents 上游协议是 Apache-2.0。本仓库没有整份拷贝该项目，推演按规格书 21.2 的节点顺序用 Mock 跑通。

## 局限

- 没有配置外部语言模型和向量模型。
- 行业目录只有信息技术和苹果样例。
- 市场温度、板块、社融在样本或正式文件不足时明确写无法判断或不可用。
- 报告的 PDF 用浏览器打印，容器里没有单独安装中文排版引擎。
- 推演不回测成交，也没有委托接口。
