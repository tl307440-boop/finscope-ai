## 二、数据质量

这些是代码里真实生效的约束，不是口号：

- 金额与财务数值一律用 `Decimal` / `NUMERIC`，**缺数不写 0**。
- 交易日只来自 `trading_calendars` 表，不靠自然日推算。
- 宏观观测按 vintage 过滤：**发布日当天还不可见**（`pit_date` 规则）。
- 公告只接受 `cninfo` / `sse` / `szse` / `sec` 白名单来源，用
  「链接 + 标题 + 发布时间」做 SHA256 去重（`news_events.dedupe_hash` 唯一）。
- 行情写入前做 OHLC 校验：`low > high` 这类坏行被拒收并计入 `rows_rejected`，
  不覆盖已入库的好数据。
- 推演评级解析不到时写 `REVIEW`，**不默认 Hold**。
- 依赖不可用时接口返回 `unavailable` / `insufficient` 并带 `notice`
  （例如没有 `FRED_API_KEY` 时美国宏观、没有正式 CSV 时中国宏观），
  **不用假数据顶上去**。
- 行情源按顺序尝试：主源东方财富 `push2his.eastmoney.com` 不可达时改用腾讯行情
  `web.ifzq.gtimg.cn`。腾讯不返回成交额，所以这类日线的 `amount` 存 `NULL`、
  页面显示「—」，**没有用 量×价 之类的办法补一个看起来合理的数字**。

## 三、RAG 对照实验（T26）

### 3.1 三组做法（规格书 §14.3 实验 A）

| 组 | 做法 | 本次能复现的结果 |
|---|---|---|
| A1 规则 | 只列出已入库数字和申报号，不做检索 | 样例记录含 80 / 120 与申报号 |
| A2 检索 | PostgreSQL 全文检索 + pgvector 混合检索（RRF 融合） | 原句能回到文档与页码；无共同词不返回 |
| A3 模型 | 引用校验失败的句子不许写入正文 | 无效 JSON 重试一次后失败 |

### 3.2 已经落地的基础设施

- `document_chunks.embedding` = `vector(1536)`，建了 HNSW（`vector_cosine_ops`）
  与 GIN 索引，检索走 `ORDER BY c.embedding <=> CAST(:embedding AS vector)`。
- 上传 → 解析 → 分块 → 嵌入 → 检索 → 引用校验的链路可用，并有单测覆盖。

### 3.3 必须如实说明的两点（答辩不要说过头）

1. **嵌入模型不是大模型**：本机没有配置 `EMBEDDING_*`，实际落库的
   `embedding_model` 是 `local-hashing-v1`——一个**本地确定性哈希向量**，
   不是语义嵌入模型。因此本实验能验证的是**检索链路与引用校验的正确性**，
   不能声称「用了大模型 Embedding 提升了语义召回」。
2. **40 家专家标注没有补造**：规格书要求的 50–100 题专家标注集需要人工完成，
   没有做，所以**数值正确率 / 引用支持率 / 拒答正确率 / 平均延迟这四个指标留空**。
   实验脚本目前只登记了公开处分样本 `002717`（2026-09-18）。

> 结论性数字（提升幅度）在没有标注集的情况下**一个都不编**。这一条与
> `AGENTS.md`「不编造数据」的约束一致。
