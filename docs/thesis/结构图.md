# 从当前代码整理的结构图

表名来自 Alembic 修订，不是设想中的库。

## 架构

```mermaid
flowchart LR
  browser[Vue 页面] --> nginx[nginx]
  nginx --> api[FastAPI]
  api --> db[(PostgreSQL pgvector)]
  worker[Worker] --> db
```

## 研究记录

```mermaid
sequenceDiagram
  participant 用户
  participant 公司页
  participant API
  participant 数据库
  用户->>公司页: 保存研究记录
  公司页->>API: POST /analysis/filing
  API->>数据库: 读取截止日可见的样例事实
  API->>数据库: 写入 analysis_runs 和 reports
  API-->>公司页: run_id
  公司页->>API: GET /analysis/runs/{id}
```
