# 市场行情四模块 Walkthrough

## 页面与路由

| 路由 | 页面 | 内容 |
| --- | --- | --- |
| `/market/indices` | 全景行情 | 全球指数与商品、短线情绪与盘面广度、成交量能（含 11:30）、两融、期指机构持仓、领涨板块与人气股、A 股指数日线（原有） |
| `/market/dragon-tiger` | 龙虎榜分析 | 关注名单中的游资/席位当日上榜个股胶囊（红买绿卖）、席位净额、外资/机构/拉萨天团汇总、全部上榜个股（折叠）、席位管理抽屉 |
| `/market/ladder` | 连板分析 | 整体晋级率/断板率、1进2/2进3/3进4+、连板梯队矩阵、昨日连板今日断板 |
| `/market/news` | 热点消息 | 财联社/东财/同花顺/金十聚合，降噪开关，级别/倾向/来源/范围筛选，板块与个股挂载；底部可展开原有“行业事件热点追踪” |
| `/hotspots` | 重定向到 `/market/news` | |

四个模块右侧共用「个股详情」面板（可收起）：分时（现价+均价+量柱）、日 K（MA5/10/20+量）、封单额/封流比、换手、流通市值、涨停原因、龙虎榜买卖前五。席位旁的游资标签点击后跳到龙虎榜并定位该席位。

## 数据来源（均无需登录）

东方财富（行情、涨跌分布、涨停池、龙虎榜、两融、期指持仓、7x24）、同花顺（人气榜、涨停池、板块、快讯）、财联社电报（已逆向请求签名）、金十数据。韭研公社异动解析需在后端 `.env` 配置 `JYGS_SESSION`（扫码登录后的会话，约两周过期），没配置时界面如实说明；开盘啦未接入。
