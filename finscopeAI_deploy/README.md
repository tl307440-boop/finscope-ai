# finscopeAI_deploy

AI 投研助手改造（数据查询 + 动态语料库 + 联网搜索）相关的设计与部署文件，单独放在这里，不混进现有的 `docs/` 与 `deploy/`。

| 文件 | 内容 | 状态 |
| --- | --- | --- |
| `AI助手改造设计.md` | 目标、架构、数据工具、语料库、向量化、联网搜索、分期，含案头核实结论与待确认项 | 设计稿，未实现 |

## 约定

- 后续这次改造新增的容器（`embedder`、可选的 `searxng`）的 compose 片段与配置，也放在这个目录，**不改动现有的 `deploy/docker-compose.prod.yml`**，上线时再由你决定怎么合并。
- 未经实测的 compose / 配置不提交，避免被误当成可用文件。
- 密钥不进仓库。
